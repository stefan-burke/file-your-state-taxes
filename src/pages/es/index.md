      # Un servicio sin costo para declarar los impuestos estatales para las personas que usaron IRS Direct File

      **FileYourStateTaxes** se integraba con el servicio Direct File del IRS para ayudarte a completar tu declaración de impuestos estatal sin costo, y este servicio ya no está activo.

      Si presentaste tu declaración con nosotros en 2025 o 2024, puedes descargar una copia de tu declaración estatal. Para obtener más información sobre cómo acceder a tus reembolsos federales y estatales, [visita nuestras Preguntas Frecuentes](/es/us/faq/)

      Para recibir ayuda para presentar tus impuestos federales y estatales sin costo, visita GetYourRefund.
