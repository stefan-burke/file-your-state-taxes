      # ¿Qué información de contacto debo usar para iniciar sesión?
  - type: markdown
    content: |-
      Si presentaste una declaración de impuestos de 2023 con nosotros, deberás ingresar el correo electrónico que usaste para crear tu cuenta.

      Si presentaste una declaración de impuestos de 2024 con FileYourStateTaxes, deberás ingresar el correo electrónico o el número de teléfono que usaste para crear tu cuenta.

      La información de tu cuenta puede ser diferente de la que usamos para comunicarnos contigo. Por ejemplo, el número de teléfono o el correo electrónico que usamos para enviarte actualizaciones puede no ser el mismo que usaste para crear tu cuenta.

      \*Nota: Si presentaste tus declaraciones de 2023 y 2024 con nosotros, es probable que hayas usado un número de teléfono para crear tu cuenta en 2024.
