      # ¿Cómo puedo acceder a mi declaración de impuestos estatales de 2024?
  - type: markdown
    content: |-
      Si presentaste tu declaración estatal de Idaho de 2024 con FileYourStateTaxes podemos ayudarte a obtener una copia. Inicia sesión en FileYourStateTaxes para descargar tu declaración de impuestos.

      Los Declarantes de Idaho pueden visitar [esta página web](https://tax.idaho.gov/guides/public-records-requests/) para descargar el [formulario STC-0](https://tax.idaho.gov/wp-content/uploads/forms/EFO00141/EFO00141_12-12-2022.pdf)6 y encontrar instrucciones para enviarlo por correo. Podrá tardar 10 días laborables para procesar el pedido y puede tener un  costo dependiendo del tamaño del envío.
